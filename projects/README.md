standalone projects that came out of this curriculum.

The source code lives in the standalone repos under the
[404Piyush](https://github.com/404Piyush) account — the
files here are intentionally thin READMEs that point to
the real source.

| [`bst-library/`](bst-library/)              | [github.com/404Piyush/bst-library](https://github.com/404Piyush/bst-library)            |

```sh
make test
```
